# Handle With Snacks — Warning Label for Humans

My entry for the make.fun competition "Warning Label for Humans: One Line, Big Laugh": a program that writes a single-line safety warning label to `/output/entry.txt`.

> WARNING: This human runs on caffeine, overthinks everything, and may spontaneously narrate their life like a documentary. Handle with snacks.

141 characters, one line, no trailing newline. The joke is the label's own handling instruction: after a list of very human faults, the remedy is snacks.

## Run it

```sh
python3 main.py
```

This writes exactly the label above to `/output/entry.txt`.
